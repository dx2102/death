# Death

Play as Death in a hospital. Read the patient's diary or skip it, then reap the soul in a short minigame. Reading the diary first makes the soul easier to catch.

## Running

Download a build from Releases, or on macOS or Linux run `./run.sh` (it fetches the libraries it needs and builds the game).

WASD moves, E or Space interacts. In the minigame the mouse aims, A/D turn the scythe, and Space or a click slices. Cut across the yellow lifeline five times in a row.
